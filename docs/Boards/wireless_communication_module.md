## Description

Low working voltage: 1\.9～3\.6V low voltage work;

High rate: 2Mbps, because the air transmission time is very short, greatly reducing the collision phenomenon in wireless transmission;

Multi\-frequency points: 125 frequency points, meeting the needs of multi\-point communication and frequency hopping communication;

Ultra\-small: built\-in 2\.4GHz antenna, small size, 15x29mm \(including antenna\);

Low power consumption: When working in response mode communication, fast air transmission and start\-up time greatly reduce current consumption;

Low application cost: NRF24L01 integrates all high\-speed signal processing parts related to RF protocol, which is convenient for using low\-cost single\-chip microcomputer;

Easy to develop: six receiving channel addresses can be set at the same time, and the receiving channel standard pin Dip2\.54MM spacing interface can be selectively opened, which is convenient for embedded applications;
