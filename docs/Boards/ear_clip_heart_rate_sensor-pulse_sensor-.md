## Description

The PulseSensor comes with a 3\-cable ribbon cable terminating in a male header\. The pinout is as follows:



Purple Wire = Analog Pulse Signal \(Vdd/2\)

Red Wire = Vdd, Power with 3V or 5V

Black Wire = Ground

## Additional information
