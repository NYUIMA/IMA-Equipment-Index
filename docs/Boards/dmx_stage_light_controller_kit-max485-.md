## Description

This low power transceiver module is based on the Maxim MAX485 IC to allow serial communication over very long cable runs \(up 4000 feet / 1200 meters\)\. Serial data can be transmitted in both directions \(half duplex\) at a data rate up to 2\.5Mbps\.
